# 暮林之战 · 剑盾战斗 3D Demo

基于 HTML5 + Three.js（CDN ImportMap 引入，零本地依赖库）构建的 3D 森林动作战斗 Demo，由 **GPT-6.2 Sol (Ultra)** 在 **Codex CLI (`codex`)** 中生成。

## 🌐 在线试玩链接 (GitHub Pages)

- **在线试玩**：<https://chan-yuu.github.io/forest-combat-gpt-6-2-sol-ultra/>

## 🎮 核心战斗机制

- **森林战场与敌人**：森林竞技场遭遇战，敌人包含**半兽人**与**半兽人统领（Boss）**。
- **近身积怒 → 怒气点（最多 3 点）**：近身挥剑命中可积攒怒气（`0 / 100`）；怒气每满一条自动转化为 `1` 个怒气点，最多储存 `3` 个，用于施放技能。
- **`1` 怒气点 · 盾击（按键 `1`）**：消耗 `1` 个怒气点施放近战盾击。
- **`2` 怒气点 · 飞盾（按键 `2`）**：消耗 `2` 个怒气点远程投掷盾牌，先后弹射撞击附近最多 `2` 名敌人后飞回手中。
- **`3` 怒气点 · 旋风斩（按键 `3`）**：消耗 `3` 个怒气点施放旋风斩。

## ⌨️ 操作说明

| 按键 | 动作 |
| --- | --- |
| `W A S D` | 移动 |
| `鼠标移动` | 瞄准 |
| `鼠标左键` / `Space` | 挥剑 |
| `Shift` | 闪避 |
| `1` / `2` / `3` | 施放 1 / 2 / 3 怒气点技能 |
| `R` | 重新开始 |
